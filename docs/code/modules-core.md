Dependency direction: `main` → `game`, `input`, `render`, `audio` (`main` triggers sounds by watching state changes: fork level, number of done zones (`playWonky` (the arpeggio, but flat and sagging) instead of `playSuccess` when the newly finished zone (not other, earlier-finished ones)'s stack has crooked boxes, `zoneWonky`), `g.bonks`, and `g.scrape` (other trucks' bonks, scrapes, box damage, fork moves, engines and reversing beepers are heard too, scaled by `hearVol` = 1/(1+distance/8), the same falloff as their horns) (speed while touching a wall without a big speed loss; a big one-step loss bumps `g.bonks` instead; both set by `wallContact` in `game.js`); `game.js` stays audio-free); `game` → `forklift`, `level`, `geom`; `render` → `pov`, `game`, `level`, `forklift`. `game.js` must never touch the DOM.

Gear: `g.fl.gear` is `'D'` or `'R'` (set in `drive`, flips only at standstill when the opposite throttle is held; idling in R — stopped, no throttle — for 3 s (`IDLE_TO_D`, timer in a `WeakMap` in `forklift.js`, not saved) flips back to D). R drives reverse lights/beeper; the GL cabin camera keeps looking forward and does not swivel round in R. `g.rv` (0..1, smoothed, set in `update`) is 1 after `LOOK_BACK_DELAY` (1 s) in R and only flips the chase camera (`main.js`).
