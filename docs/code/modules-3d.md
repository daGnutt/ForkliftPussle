# Modules: cabin view and GL renderer

Part of the code guide (see `../CODE_GUIDE.md`).

Both cabin renderers (`pov.js` and `gl/views.js`) import `drawRepairEdgeArrow` from `repairhint.js` to draw the repair-station hint at the viewport edge.

| File | Role | Key exports |
|------|------|-------------|
| `js/pov.js` + `js/pov/` | Cabin view (rebuilt as modules): a small polygon-projection renderer. `pov.js` is the `drawPov` orchestrator (sky/floor gradients, then ceiling, grid, floor decals/marks, reversing light, faces far to near with the zone labels interleaved by distance, reversing-light wall climb, damage popups). `pov/camera.js`: constants (`BOX_H` 0.5, `PAL` 0.1, `WALL_H`, eye: 90° FOV (GL cabin camera: 100°, `GL_HFOV` in `gl/camera.js`), local x −0.5, height 0.95 + 55% of `g.ef`, a smoothed copy of `g.hf` the eye trails by ~0.22 s (set in `update`); `drawPov` shifts the horizon by `EYE_TILT·(g.ef−g.hf)` so the view tilts up/down as the forks lead) and projection (camera space forward/right/up, near-plane clipping, polygon/line helpers). `pov/scene.js`: `buildFaces` turns walls, pallets (centre + corner blocks), boxes (including box-coloured oil barrels with oil-drop decals), forks (`addForks`: blade, tapered thin tip, upright shank and carriage plate per tine set), chargers and ceiling fixtures into prism faces (wall sides in 1-tile segments with a checker tint, tines in 0.2 segments so they sort correctly against the box above them), back-face culled, dropped when wholly behind/beside the view or beyond `MAX_DIST` (`offscreen` in `camera.js`) sorted far to near, then faces wholly hidden behind nearer wall faces are dropped (`dropHidden`: walls span floor to ceiling, so per screen column anything further than a fully covering wall is invisible; pixel-identical). Overhead fixtures only within 20 tiles, floor decals (batched per fill colour) within 16, wall/box decals within `DECAL_MAX_DIST` (20); fork level h is drawn at height h·(BOX_H+PAL). A just-released stack carries `dropFrom` (index of its first released box; set in `forkDown`, cleared in `update` once `g.hf` reaches it) so those boxes lower with the forks instead of teleporting. `pov/face.js`: `drawFace` (flat colour + distance darkening blended into one opaque `rgb()` fill instead of a second translucent overlay, faces off-screen horizontally skipped; wall signs except door/exit are lowered by `SIGN_DROP` so they hang around eye height with the forks at level 1) and the wall/box/charger decals (`WALL_SIGNS` table, shared `faceShapes` helper). `pov/floor.js`: ceiling with joists, perspective tile grid (`povGrid`), zone quads, parking spot (green once all zones are done and score is enough, with heading arrow), reversing light. `pov/overlay.js`: `zoneLabelItems`: floating `×count` zone labels as painter items (`{d, draw}`, `d` = distance to the label minus 0.75) that `pov.js` merges into the far-to-near face loop, so walls/boxes in front clip them and damage popups. Drawn top-left by `render.js` (full-screen with a small overview when `view.povBig`, toggled by M in `main.js`) | `drawPov` |
| `js/gl/` | (Chase camera tuning in `gl/camera.js`: `chaseRig` zooms out up to `ZOOM_OUT` (20%) with speed and returns `tz`, a look-at height of `TARGET_LIFT` × fork height so raised stacks stay in frame; `chaseDrift` speeds up by up to `DRIFT_STEER` with steering lock; it and the speed zoom use a low-passed speed (`SPEED_SMOOTH`, per-game `camState`), and the camera only changes side (behind ↔ in front) after the truck has reversed for `FLIP_TIME` s or `FLIP_DIST` tiles, so shuffling doesn't swing or pulse the camera.) (Menu option "Bare forks", hotkey B, `localStorage` `forklift-bare-forks` = `1`, `setBareForks` in `gl/models.js`: in the GL cabin view `dynamicMeshes` skips `addForklift` and `addForks(…, hideMast)` skips chains/mast head/cylinder rod, leaving carriage and tines.) True-3D renderer (raw WebGL2, no deps) used by default for the overview, the cabin view and the look windows; the Canvas 2D renderers (`pov.js`, `render.js` `drawWorld`) remain as the fallback when `getContext('webgl2')` fails (or the menu option "3D graphics (WebGL)" / `?gl=0` turns it off; pref `localStorage` `forklift-gl-off`; `setGlEnabled` in `main.js`). `renderer.js`: in the game a visible WebGL canvas `#gameGl` (`attachGlCanvas`, in a `#stage` wrapper behind the now transparent 2D `#game` canvas; `beginGlFrame` at the start of `draw` sizes and clears it to the theme bg and clears the 2D canvas, each `drawGl` call renders into its viewport/scissor rect and punches that rect out of the 2D canvas with `clearRect`, so 2D HUD/labels draw on top and there is no per-frame GL→2D copy, which was slow in Firefox windowed mode; without WebGL `beginGlFrame` returns false and `draw` paints the opaque 2D bg as before), otherwise (splash3d) one hidden WebGL canvas (grow-only), a sky program (`SKY_FS`, overview/chase only: fullscreen triangle drawn first, no depth, view ray from the inverse `uVP`: starry void in dark mode, blue gradient with fbm clouds in light mode) for the void outside the level, one GLSL program (hemispheric ambient + sun lambert, distance fog in the cabin view, zero normal = unlit, plus up to `LIGHT_MAX` (24) real point lights (`dynamicMeshes().lights`, uniforms `uLP`/`uLC`/`uLD`; optional spot `dir`/`cone`): in dark mode (`theme().dark`) `darkLights` in `scene.js` supplies, for every non-ghost truck (own and other players', nearest `LIGHT_MAX` kept), the forklift's two A-pillar headlights (spots), white reverse lights, red brake lights (`g.fl.brake`, set by `drive`) and a dim always-on red tail glow, with a low ambient (`DARK_LIGHT`) standing in for the ceiling fixtures, which give no point light and the blue floor reverse pool replaced; disco spots fill the remaining slots, nearest to the eye), passes opaque → alpha-blended decals (depth write off, polygon offset); on the hidden-canvas path the result is copied into the given 2D canvas with `drawImage` right after each render; returns a projector (world → css px) for 2D overlays. `scene.js`: `staticMeshes(g, mode)` (floor, grid, decals, walls, chargers, plus wall decals and ceiling/joists/fixtures/doorways for `'pov'`; cached per game state/theme/decals flag, uploaded once) and `dynamicMeshes(g, mode, eye)` (stacks, carried stack, forklift, forks, zone/parking marks (in `'ov'` the unfinished zones' `×count`, placed by `zoneLabelPos` in `game.js` — below the zone, or above it when a wall would cover that spot (for any drop point of its area, so the whole area is labelled on the same side) — is painted on the floor with a stroke font, `floorText`, so the forklift drives over it), blob shadows, reversing light, disco) rebuilt every frame; modes `'pov'` and `'ov'` (the overview has no ceiling and a solid forklift roof; walls are full `WALL_H` height; the top-down overview cuts every wall at `OV_WALL_H` in the fragment shader (`uClip`, `wallClip` in `scene.js`) and `wallCaps` adds a top at that height so they don't look hollow, while the third-person view (`cam.chase`, set by `chaseCamera`; `groundFootprint(cam)` unprojects the screen corners onto the floor, and in chase mode `drawOverview3d` returns it so `drawOverview` passes it as `cam.poly` and `drawMiniMap` outlines that polygon instead of a rectangle) shows them full height). `models.js`: forklift (cabin view uses a low hood and thin posts), forks, pallets, boxes. `mesh.js`: vertex builder (stride 10: pos, normal, rgba). `mat.js`: matrices/projection. `camera.js`: `povCamera` (eye fixed at seat height `EYE_Z`, never translating vertically; it also turns its head into the turn (`headTurn`, ≤ `HEAD_TURN` rad, proportional to the steering angle only, also at standstill and when reversing; it never looks backwards) and only pitches, via a real rotation, to look at the fork tips at `g.ef`, raised by `LOW_LIFT` when the forks are low (fading out by level 2) so the view looks more forward than down; unlike the 2D cabin view) and `overviewCamera` (tilted perspective, `up` = world direction pointing up the screen) and `chaseCamera(g, w, h, tiles, heading, orbit, eye2)` (look-at camera built on `chaseRig`; `chaseOrbit(g, pos, ang)` swings the floor position around the truck for the user's Q/W (45°) / drag orbit in `main.js`, which then keeps the camera there: the floor trailing distance `maxD` is `CHASE_REACH` (0.5) × the distance that frames `tiles`; the eye hangs at a fixed height (from tilt, `CHASE_TILT`; default zoom = `CHASE_DEFAULT` (0.5) × the overview tiles, min `CHASE_TILES` = 7) and its floor position `view.camP` (kept by `render.js`, null = start behind the forklift) only slides when the tines' middle gets further than the maximum distance (or closer than `CHASE_MIN` of it) — no swing in reverse — and, while the truck moves, `chaseDrift` (main loop) slowly drifts it to the distance limit behind (forwards) or in front of (reverse) the truck, then it yaws/pitches to keep the tines' middle centred; `view.camA` = resulting eye→truck heading, used by the compass; `g.rv`/`LOOK_BACK_DELAY` are now unused by the chase camera), `view.orbit` {yaw, tilt} (drag/Q/W) swings the eye around the truck / sets its height and max distance (in the flat overview it instead rotates around the unchanged view centre, and on driving springs to the nearest 90° yaw; Q/W press springs it a quarter turn via `orbit.goal`) and springs back to `CHASE_TILT` when driving; `drawOverview3d`'s `chase` = visible tiles, orbit ignored; zoom slider `#chaseZoom` (0–100, 100 = `CHASE_TILES` = 11 tiles, 0 = zoomed out 80%, `chaseTiles`/`chaseZoom`, `view.chaseZoom`, `localStorage` `forklift-chase-zoom`); if a wall hides more than half of the forklift (`truckVisibility`, ray samples vs `g.walls`), `clearChaseTilt` finds a smaller tilt (camera orbits upwards); `render.js` stores it as `view.chaseLiftTarget` and `main.js` eases `view.chaseLift` toward it (subtracted from the orbit tilt when drawing); `#chaseZoomReset` clears it; until moved (null) the top-down overview fits the map and the chase camera uses the overview's tiles, `view.ovTiles`; the overview has its own zoom, `view.zoom` (same 0–100 scale and slider; null = fit the map), which when set zooms the top-down GL overview, centred on the forklift (`drawOverview` in `render.js`, orbit still applies), and the software (2D) overview, which then draws at `rh / chaseTiles(zoom)` px/tile in the follow-camera path; the menu option sets only the chase zoom). Switching between overview and chase camera swoops: `drawOverview3d` (`swoopCamera` in `views.js`) blends from the last drawn camera pose to the new one with `blendCameras` (`camera.js`, uses `cam.pose`) over `SWOOP_S` (0.8 s) `views.js`: `drawPov3d`/`drawOverview3d` (optional `orbit` `{ yaw, tilt }`: camera centred on the forklift and swung around it; set as `view.orbit` in `main.js` by dragging on the canvas or Q/W in the 3D overview; `drawPov3d`/`povCamera` take `look` `{ yaw, pitch }` (`view.look`, same inputs in the cabin view); driving sets `view.snap` and `springBack` eases both back to rest)/`drawLook3d` (return false when GL is unavailable) plus the 2D cabin-view `×count` zone labels and damage popups drawn through the projector. Wall/charger decals reuse `paintWallDecals`/`chargerDecal` from `pov/face.js`. In `'ov'` the wall decals are painted too, at full size. Known simplifications: blob shadows only, no side dents on boxes, no lower-layer colour numbers in the overview. | `drawPov3d`, `drawOverview3d`, `drawLook3d`, `staticMeshes`, `dynamicMeshes` | `js/gl/particles.js` (`addParticles`, called from `dynamicMeshes`): purely visual particle system, state per game in a WeakMap, stepped once per `g.clock` change. It watches per-truck `bonks`/`contact` (sparks + dust + a short orange point light in dark mode), `scrape` (continuous sparks), `slip` (tyre smoke from the wheels), the `hitCount`/`hits` popups (damage smoke + cardboard chips), `carried` going null (dust when a stack is set down) and `zoneDone` flips (confetti). `game.js` feeds it two truck fields, both synced in `net/protocol.js` / `predict.js`: `contact` (`{x, y, nx, ny}`, last wall hit point + push direction) and `slip` (0..1, set by `tireSlip` when a driven truck is pushed back at < `SLIP_MAX_SPEED`, or shoved by another truck).
